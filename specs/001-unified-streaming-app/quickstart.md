# Quickstart Guide: Unified Streaming Application

**Feature**: Unified Streaming Application  
**Date**: 2025-01-27  
**Status**: Complete

## Getting Started

This guide provides step-by-step instructions for setting up and using the Unified Streaming Application on Android TV and Fire TV devices.

## Prerequisites

- Android TV device (Android 5.0+ / API 21+) or Fire TV device (Fire OS 5+)
- Internet connection
- IPTV playlist URL (M3U/M3U8 format)
- Debrid service account (Real-Debrid, Premiumize, or AllDebrid) - optional but recommended

## Installation

1. **Download and Install**
   - Install the SimpleTV APK on your device
   - Grant necessary permissions (Storage, Network access)

2. **First Launch**
   - App will open to IPTV login screen
   - Enter your Xtream Code credentials or playlist URL

## Initial Setup

### IPTV Configuration

1. **Login Screen**
   - Enter server URL (e.g., `http://your-iptv-server.com`)
   - Enter username and password (if using Xtream Code)
   - Or paste your M3U/M3U8 playlist URL
   - Tap "Connect" to validate and save credentials

2. **Channel Loading**
   - App will automatically parse your playlist
   - Channels will be organized by country/category
   - EPG data will be loaded if available

### Debrid Service Setup (Optional)

1. **Access Settings**
   - From home screen, navigate to Settings
   - Select "Debrid Services"

2. **Add Debrid Account**
   - Choose your service (Real-Debrid, Premiumize, AllDebrid)
   - Enter your API key
   - Tap "Validate" to test connection
   - Save account for future use

## Navigation Guide

### Home Screen

The home screen features four main cards:

- **Live TV**: Access IPTV channels and live streaming
- **Movies**: Browse movie content from debrid services
- **Series**: Browse TV series from debrid services  
- **Debrid**: Access all debrid content organized by platform

### TV Remote Controls

- **Directional Pad**: Navigate between options
- **OK/Select**: Choose selected item
- **Back**: Return to previous screen or exit app
- **Menu/Info**: Access additional options or help
- **Channel Up/Down**: Switch channels when watching live TV

### Live TV Interface

1. **Three-Panel Layout**
   - **Left Panel**: Country/category list with flags
   - **Center Panel**: Channel list with logos and info
   - **Right Panel**: Current program information and EPG

2. **Channel Navigation**
   - Use directional pad to navigate categories and channels
   - Press OK to select and stream a channel
   - Use channel up/down buttons for fast switching

3. **Full Screen Mode**
   - Press OK on any channel to start streaming
   - Use channel up/down for instant channel switching
   - Small channel list overlay appears during switching

### Debrid Content Interface

1. **Netflix-Style Rows**
   - Horizontal scrolling rows organized by platform
   - Categories: New Movies, New Series, Trending, etc.
   - Platforms: Netflix, Disney+, HBO, Premium content

2. **Content Selection**
   - Navigate to desired content using directional pad
   - Press OK to view content details
   - Select quality and language options

3. **Streaming**
   - Choose preferred quality (HD, 4K, SD)
   - Select audio language and subtitles
   - Press OK to start streaming

## Search Functionality

## Troubleshooting

### Common Issues

1. **Channels Not Loading**
   - Check internet connection
   - Verify playlist URL is correct
   - Ensure credentials are valid
   - Try refreshing playlist in settings

2. **Streaming Issues**
   - Check device storage space
   - Verify internet speed
   - Try different quality settings
   - Restart the application

3. **Debrid Service Issues**
   - Verify API key is correct
   - Check account quota and expiration
   - Ensure service is active
   - Try different debrid service

4. **Remote Control Issues**
   - Ensure device supports TV remote
   - Check remote battery levels
   - Try using device remote app
   - Restart the application

### Performance Optimization

1. **Improve Streaming Performance**
   - Use wired internet connection when possible
   - Close other applications
   - Clear app cache periodically
   - Restart device if needed

2. **Reduce App Size**
   - Clear unused data in settings
   - Remove old watch history
   - Update to latest app version
